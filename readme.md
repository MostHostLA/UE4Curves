# 🚀 UE4 Curves Extension

> **A specialized Unreal Engine 4 plugin providing advanced curve manipulation tools and optimized runtime evaluations.**

---

## ✨ Features

- ⚡ **Optimized Evaluation** – High-speed curve sampling optimized for real-time gameplay logic.
- 🎨 **Visual Tweaks** – Smooth interpolation and customized mathematical easing functions.
- ⚙️ **Data-Driven** – Easily convert external data or mathematical expressions into UE4 Curve Assets.

## 🚀 Getting Started

Follow these steps to integrate this extension into your UE4 project.

### 🔧 Installation

1. **Download from https://mosthostla.com/gamedev/ue4curves/*

2. **Enable the plugin**:
- Open Blender
- Click on Edit and select Preferences (Edit > Preferences)
- Within the Preferences Panel click the Add-ons Tab.
- On the Add-ons tab click the Install Button at the top right and select the Zip file you downloaded.
- Right after the file install is complete check the checkbox next to "Export: UE4FBX".
- That's All! You can now find the new "UE4 FBX (.fbx)" options wihtin your File>Import and File>Export menu.
